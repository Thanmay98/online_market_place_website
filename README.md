# Marketly — Basic Marketplace Website

A simple responsive marketplace demo built with plain HTML, CSS, and JavaScript.

## Run it
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.

## Features
- Responsive layout for desktop and mobile
- Product cards with sample prices and ratings
- Search products by name or category
- Filter by category
- Sort by price and rating
- Add products to cart, change quantities, remove items
- Sample subtotal and delivery calculation

## Important
This is a front-end demo. It does not have a backend, user accounts, inventory database, real checkout, or payment processing. Product data is stored in the JavaScript file. For a real marketplace, add a backend/API, database, authentication, order management, and a trusted payment provider.
